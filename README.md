# 🌍 Just Planet Earth

![Deployment: gh-pages](https://github.com/igoresso/just-planet-earth/actions/workflows/deploy.yml/badge.svg)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This project visualizes a 3D representation of the Earth with modern rendering techniques powered by WebGPU. It's designed as a playground for shader experimentation and graphics exploration.

## ✨ Features

- **Realistic Sun Positioning**: The sun's location accurately matches the real sun position based on astronomical calculations using the NOAA/USNO solar position algorithm
- **WebGPU Rendering**: Modern graphics pipeline for high-performance 3D visualization
- **Real-time Earth Rotation**: Earth rotation synchronized with Greenwich Mean Sidereal Time (GMST)
